## Fixes

- **Updates download only what changed.** Exordium now unpacks just the files that differ from your installed copy,
  instead of rewriting every file on each update. Most updates now replace a single file. This also keeps Windows
  Defender from re-scanning, and sometimes wrongly quarantining, the unchanged game loader files, which made updates
  fail.
- 0.2.5 was first published with the previous version's program inside, so updating appeared to do nothing and offered
  0.2.5 again. The release was replaced, and releases are now checked so this cannot happen again.
