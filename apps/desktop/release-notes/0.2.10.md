## New

- **One mod browser.** Internet Archive and ModDB results now share one focused catalog instead of separate source
  pages, with a centered layout that stays comfortable on wide screens.
- **ModDB releases stay together.** Multiple files and versions from the same ModDB project are grouped into one card,
  where the release can be selected before installing.

## Improvements

- **Browsing continues as you scroll.** More catalog results load automatically near the bottom of the page, replacing
  the Show more button.
- **Updates are easier to understand.** Exordium's own version, release notes, and update policy now live under Help,
  Updates. Settings, Updates is reserved for installed mods and can hide their available-update cards from the library.
