## Fixes

- Exordium now saves its window position right before an update restarts it, so the updated copy always opens where the
  old one was, maximized or not. Before, a move made in the last few seconds before the restart could be lost.
- The same applies when Exordium restarts itself after its browser view stops responding.

Updating from 0.2.1 or earlier: those versions never saved the window's position, so the first start after this update
opens in the default place. From then on it is remembered.
