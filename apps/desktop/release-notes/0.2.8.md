## What's new

- **One game loader for every classic core.** Diablo II 1.00 through 1.13d now launch through one immutable Exordium
  executable instead of a separately stamped loader for every game version.

## Fixes

- Boxes keep the core's authentic `Game.exe` for version detection while Exordium runs the shared loader from its own
  installation. This avoids creating or rewriting equivalent executables for each core and gives Windows Defender one
  stable file to scan and recognize.
