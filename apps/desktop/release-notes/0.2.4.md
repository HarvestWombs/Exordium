## What's new

- **Patch notes in Settings › Updates.** The Updates card now lists what each recent version changed, newest first, with
  the installed version and the one on offer marked.
- **Updates are found sooner.** With Check automatically on (formerly Check on startup), Exordium looks for a new
  version every 15 minutes while it runs, not only when it opens.
- **A ready update is a toast.** Instead of turning the status bar into a notice, a downloaded update shows a toast that
  stays until you choose Restart now, What's new or Later.
- **Toasts have a new look.** Updates, the D2SE import reminder, confirmations and errors share one design, each in its
  own colour, and keep working as before.
- **New icon.** The sealed cube now glows blue.

## Fixes

- The window controls' tooltips appear under each button instead of all in the same place.
- Installation location and the uninstall confirmation show the mod's folder with one kind of slash.
- The settings scrollbar sits at the window's edge instead of partway across wide windows.
- Exordium no longer closes itself at start when an earlier run ended uncleanly and the new run gets the same port.
